Mealie

A Place For All Your Recipes

A self-hosted recipe manager, meal planner and shopping list with a RestAPI backend and a reactive frontend built in Vue.

Quick start

You can deploy with either SQLite (default) or Postgres. SQLite is sufficient for most use cases.

SQLite Default Self-contained and zero-configuration. The ideal choice when you have 1-20 users. PostgreSQL Worth considering if you need to support many concurrent users, or want fuzzy search.

Creating recipes

Create recipes from hundreds of websites by simply providing a URL, copy/paste structured HTML or JSON, or build one from scratch using the integrated editor.

Meal planning

Mealie uses a calendar like view to help you plan your meals. It shows you the previous day and the next 6 days by default. Use the random recipe buttons or add an entry by hand.

Mealplanner demo
Meal planner assets/img/home/meal-planner.png

Shopping lists

Keep track of what you need to buy for your next meal. Add items directly to the shopping list, or link a recipe and all of its ingredients to track meals during the week.

Key features

Import Recipes

Quickly and easily import recipes from sites around the web using the built in recipe scraper.

Automatic Backups

Keep your data safe with automatic backups in any format supported by Jinja2 templates.

Rich User Interface

Use a beautiful and intuitive user interface to create, edit, and delete recipes. Recipe editor supports markdown syntax.

Meal Planner

Create Meal Plans for the week, month, or year.

Users

Add new users with sign-up links or simply create a new user in the admin panel.

Groups

Full multi-user support with groups for sharing recipes and meal plans with family.

Webhooks

Schedule webhooks to send notifications to 3rd party services with todays Meal Plan data.

Open API

API driven application gives you full control of the backend server with interactive documentation.

Import from other apps

Create recipes from hundreds of websites by providing a URL, or migrate from another recipe manager.
